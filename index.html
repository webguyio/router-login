⚠️ Still Having Trouble?

  • Make sure you're connected to your home WiFi, not cellular data
  • Check that your device is on the same network as your router
  • If using an ad blocker, try temporarily disabling it and refresh the page
  • Look for a sticker on your router with the admin IP address
  • Try opening Command Prompt/Terminal and type: ipconfig (Windows) or ifconfig (Mac/Linux), then use the "Gateway" IP
